# Icon prompts — Motherboard: Ferrond

Every prompt below is complete: copy one code block into the image generator.
All prompts share the same style; only the **Subject** changes.

**Where to save:** put each finished image (PNG or WebP, any size) into
`E:\01_Dev\motherboard-ferrond\assets\icons\` under the file name given in the heading.
Claude crops and converts them to 512 × 512 WebP.

## Currency — flat UI symbols for the character sheet

Bits, Bytes and Chunks are digital money, not objects. These icons only appear tiny next to
the numbers in the character sheet, so they use their own **flat** style.
All three share the **same base shape** (the round Bits symbol); with each step up the color
changes and more chip detail is added: copper/orange → silver → gold
(8 Bits = 1 Byte, 8 Bytes = 1 Chunk).

**Tip:** attach the finished Bits image as a reference when you generate Bytes and Chunks.

### Bits → `currency/bits.webp` ✅ done

```
Minimal flat UI icon for a digital currency in a sci-fi game interface. Flat vector style: bold, simple geometric shapes, one main color plus one darker shade of it, a thick clean dark outline. No texture, no grime, no gradients, no shading, no reflections, no 3D, no perspective, straight front view. Centered on a square 512×512 canvas, filling about 70% with generous padding. Transparent background, no text, no letters, no numbers, no logos. It must stay readable at 16×16 pixels, like a currency symbol next to a number in a character sheet. Subject: one data bit — a single round dot shaped like a small indicator light, warm copper orange, with a bright inner core and one thin ring around it.
```

### Bytes → `currency/bytes.webp`

```
Minimal flat UI icon for a digital currency in a sci-fi game interface. Use the attached reference icon for style and base shape: the same round symbol with a solid inner disc, a thin dark gap and an outer ring, the same thick dark outline and the same flat look. Flat vector style, one main color plus one darker shade of it. No texture, no grime, no gradients, no shading, no reflections, no 3D, no perspective, straight front view. Centered on a square 512×512 canvas, filling about 70% with generous padding. Transparent background, no text, no letters, no numbers, no logos. It must stay readable at 16×16 pixels. Subject: one data byte — the same round symbol, now in cool silver. On the inner disc sits a small square microchip as a simple dark silhouette with short pins on each side; four thin circuit lines run from the chip outwards, each ending in a small round solder dot.
```

### Chunks → `currency/chunks.webp`

```
Minimal flat UI icon for a digital currency in a sci-fi game interface. Use the attached reference icon for style and base shape: the same round symbol with a solid inner disc, a thin dark gap and an outer ring, the same thick dark outline and the same flat look. Flat vector style, one main color plus one darker shade of it. No texture, no grime, no gradients, no shading, no reflections, no 3D, no perspective, straight front view. Centered on a square 512×512 canvas, filling about 70% with generous padding. Transparent background, no text, no letters, no numbers, no logos. It must stay readable at 16×16 pixels. Subject: one data chunk — the same round symbol, now in rich gold. On the inner disc sits a larger square microchip as a simple dark silhouette with short pins on all four sides and a small round dot in one corner; eight thin circuit lines run from the chip outwards, each ending in a small round solder dot, and the outer ring carries four small square connector pads.

## Toolbar — shown in the scene controls on the left

Foundry draws toolbar icons as one flat color (it follows the UI theme), so these are
**silhouettes**: only the shape counts, colors are ignored. Save as PNG or WebP with a
transparent background.

Put the full-size image into `art/originals/<name>.webp`; `npm run icons` makes the
128 px toolbar version in `assets/icons/tools/`.

### Screw (Scrap Reward) → `art/originals/screw.webp` ✅

```
Minimal flat glyph icon for a game toolbar. A single machine screw, seen from the side and tilted about 45 degrees: a round slotted head and a threaded shaft with four or five clear thread ridges. One solid silhouette in plain white on a transparent background, bold simple shapes, no outline, no shading, no gradients, no texture, no 3D, no perspective, no text, no letters, no numbers, no logos. Centered on a square 512×512 canvas, filling about 75%. It must stay readable at 20×20 pixels.
